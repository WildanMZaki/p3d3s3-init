Tentang Kegiatan

Kegiatan ini diadakan untuk memperkuat dasar pemahaman web bagi mahasiswa baru D3 Teknik Informatika sebelum melangkah ke pembuatan aplikasi yang lebih rumit.

Fokus pembahasannya mencakup struktur dokumen yang semantik, kalkulasi box model yang tepat, serta penataan layout adaptif menggunakan Flexbox murni.

Materi Utama

HTML Semantik

Mengenal anatomi dokumen, pemilihan tag yang bermakna, dan hierarki heading untuk keterbacaan serta aksesibilitas yang baik.

CSS Box Model

Mengatur margin, border, padding, dan memahami cascade CSS agar style tampilan tidak saling tumpang tindih.

Flexbox Responsif

Menyusun tata letak halaman yang adaptif di berbagai ukuran layar tanpa memicu scrollbar horizontal pada tampilan kecil.
